# 大工の計算ツール集

ブラウザだけで使える、大工仕事向けの計算ツール集です。

## 収録ツール

- 階段角度計算: `stair-angle.html`
- 斜め廻り縁 計算機: `moulding-calculator.html`
- 円弧・半径 計算: `arc-calculator.html`

## GitHub Pages で公開する手順

1. GitHubで新しいリポジトリを作る
2. このフォルダの中身をアップロードする
3. `Settings` から `Pages` を開く
4. `Deploy from a branch` を選び、`main` / `/root` を指定する
5. 表示されたURLにアクセスする

トップページは `index.html` です。
